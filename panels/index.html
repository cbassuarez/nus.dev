The panels

What the app actually puts in front of you. Each one below is drawn from the same tokens, rule weights and metric table the application draws it with, and links the module that builds it. The descriptions are those modules’ own, compressed — nothing here was invented for a website.

Everything on this page runs today inside the composite spike on Windows. The spike log says what that means.

The palette⌘K

One field for everything addressable: your tabs first, then actions, then opening or searching what you typed. URL and search are auto-detected and both rows are always offered, so it never guesses wrong on your behalf. Every settings row is a palette row too, which is why there is no menu bar.

  • go — tabs, actions, open or search
  • new — profiles for a shell, or a URL for a page
  • url — address the browser pane
  • Recent commands come back as rows you can run again

Ask⌘⇧?

A panel beside the shell for the moment you feel dumb. One line in, a few command blocks out. It can answer “why did that fail?” because the shell, the working directory and the last command’s output are already attached to the question — you are not pasting context into a chat window.

  • Insert at the prompt, Run, or Copy
  • Backends are whatever the machine has: claude -p, codex exec, Copilot through gh, ollama, or the API through curl
  • NUS_ASK_CMD takes anything that reads a prompt on stdin
  • Not a chat — the last few turns stay for scrolling, nothing more

-- what should a new tab look like?
function new_tab(ctx)
  if ctx.local_site then
    return { signal = hue(14) }
  end
  -- a stack keeps its parent's family
  if ctx.parent then
    return { signal = ctx.parent.signal }
  end
  return { signal = hue(ctx.index * 47) }
end

Stacks, coloured by rule

A tab that spawns another nests under it, as deep as it goes — a shell that opens a URL, a page that opens a link, an agent that opens a tab. A stack folds to one row and walks with ⌘⇧[ ]. What each one looks like is not ours to decide: new_tab(ctx) is handed the kind, the index, the profile, the theme and the parent’s colours, and returns a look.

  • Drag a row onto another to nest it, or between rows to move it
  • new_space, on_page → boosts, on_event → a sound cue
  • Sandboxed Luau: no io, no os, no FFI
  • Hot-reloads on save; RESET returns to Broadsheet

The atlas

What greets a launch: the last session to restore, and the recent pages, shells and windows to pick from instead. The icon’s band completes one orbit as the panel rises. Esc starts fresh. It is never on the splash — the splash is the drawing and nothing else.

  • Restores profiles, cwds, URLs, scroll — and each shell’s scrollback as read-only history above the fresh prompt
  • The planet in the header calls it back later
  • On demand, on launch, or persistent

The site panel

The gear at the end of a URL row, per host. Zoom that is remembered, autoplay, JavaScript, cookies to block or clear, the rules’ boosts, content blocking — and every permission the site was ever given, each one forgettable. Band answers are remembered and answered without asking again.

  • Kept in profile/sites.json
  • The request handlers read the same table, so it applies as the page loads
  • Local sites are marked here and around the page

Esc closes · Ctrl+↵ keeps it in the stack

PeekAlt+click

Alt-click a link and it floats over the page behind a scrim, without your leaving. Esc or a click outside closes it; Ctrl↵ keeps it as a page in the tab’s stack. A peek is a tab the sidebar does not list, so every pane path already serves it — there is no second code path to keep honest.

  • Keeping it lands it in the stack, unfocused
  • Nothing blurs: the scrim is flat, the edge is 2px, the shadow is a hard offset

Picture-in-picture

Ours, in the compositor — not Chromium’s. The tab’s own texture, cropped to the video’s rect by an injected script that also scrolls it into view, drawn into a small always-on-top window. No second decode and no DRM problem. It appears when a playing video’s tab leaves view and goes back when you return to it.

  • Transport keys act on the element through CDP, so sites cannot hide them
  • ←/→ ±10s · Space play-pause · ,/. frame-step · ↑/↓ volume
  • Wheel scales around the cursor; corners snap

TilesCtrl+⇧+D

Select tabs with Ctrl+click, then tile them: two side by side, three as an L, four as a grid. The tiling belongs to those tabs and shows whenever one of them is active, so it is a property of your work rather than a mode you are in.

  • Dividers drag; CtrlAlt+arrows walk, with Shift to swap
  • Closing a tiled tab re-tiles the rest
  • A shell and a page tile together — they are peers

CompactCtrl+⇧+B

The sidebar down to a 48px column of icons, the top strip hidden until the pointer reaches the edge. They are the same rows, so clicks, drags, selection and the tab menu all work unchanged — this is a width, not a mode.

  • The hovered row’s name shows beside the column
  • Under 900px the split collapses and settings become tiles that drill in
  • Side, reveal, grace and fullscreen behaviour are all config
