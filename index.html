The command line

Terminal-side

Colouring and prediction happen in the terminal, not in your shell. Nothing to install, no plugin to keep current, and it works the same in pwsh, bash, zsh, fish and cmd — including over ssh, where a shell plugin is not yours to add. 

❯ cargo test -p nus-vt --nocapture "kitty"  --release
  └ command · flag · string · ghost from history
Token classes

Command, flag, string, number, path, operator — classed as you type, coloured from the theme's ANSI slots. predict.rs

Prediction

The most recent history entry that continues the line ghosts after the caret. Right or End at the end of the line accepts it.

How it knows

OSC 133 prompt marks say where the command begins, so the terminal can tell a command line from program output.

History

Per profile, in profile/history. Recent commands are palette rows you can run again.

Blocks

Each command is a block: a hairline where it starts, a gutter rule on hover, chips to copy its output or re-run it, Ctrl+triple-click to select the output, scrollbar ticks at the prompts. term.rs:778

Shell hooks

Injected automatically — PowerShell -EncodedCommand, bash --rcfile, zsh ZDOTDIR, fish -C, cmd PROMPT. nushell already has it. AUTO or OFF.

Assistants

Whatever the machine has: claude -p, codex exec, the Copilot CLI through gh, ollama run, or the API through curl. NUS_ASK_CMD for anything else. The router is a config table. Shipped ask.rs

The URL rule

A whole line at a fresh prompt that parses as a URL opens in the split on ↵; Ctrl↵ runs it as a command instead. Any editing key disqualifies the line. Bare words never trigger. PRODUCT.md:83

-- what should a new tab look like?
function new_tab(ctx)
  if ctx.local_site then
    return { signal = hue(14) }
  end
  -- a stack keeps its parent's family
  if ctx.parent then
    return { signal = ctx.parent.signal }
  end
  return { signal = hue(ctx.index * 47) }
end

Tiles

Select tabs with Ctrl+click, then Ctrl⇧D: two sit side by side, three make an L, four a grid. The tiling belongs to those tabs and shows whenever one of them is active; dividers drag, CtrlAlt+arrows walk them, and closing one re-tiles the rest.

Peek

Alt+click a link and it floats over the page behind a scrim without your leaving. Esc or a click outside closes it; Ctrl↵ keeps it as a page in the tab's stack. A peek is a tab the sidebar does not list, so every pane path already serves it.

Customization

Where it goes further

The axis Arc and Zen stop at. Every surface is a value you can set, and the interesting ones are functions you can write.

rules.luau

new_tab(ctx) and new_space(ctx) return a look; on_page(ctx) returns per-site CSS and JS; on_event(ev) returns a sound cue or silences it. Sandboxed: no io, no os, no FFI. PRODUCT.md:188

Surface

Ramps of 2–4 stops with angle, loop, aurora drift and breath. Textures — grain, stipple, stitch, linen, halftone, scale — on the carapace, the chrome or the panes, never on content or video.

Theme

Paper, ink and page tokens per mode, sixteen ANSI colours with a real HSL picker, contrast grade and saturation. Import from Ghostty, Windows Terminal, VS Code or base16. Twenty stock themes, contrast-audited by a test.

Cursor

Shape, hollow or hidden when unfocused, blink never / after 2s / always, colour, and motion: jump, glide or comet.

Motion

One easing, 80–220 ms base, and a register slider from 0.45× snappy to 2.2× cinematic. Reduce-motion follows the OS or is forced.

Scrolling

The shell rides neoscroll's curves — a line at a time on an eased clock, more ticks extending the trip. Pages keep Chromium's, switchable. scrolling.rs

Sound

Seventeen synth recipes on cpal across fourteen events, each previewable, each overridable from rules. sound.rs

Settings are the file

Every edit writes ~/.config/nus/init.luau. The file is the source of truth and hot-reloads. Every settings row is also a palette row.

Provenance

Ported, not imitated
The caret

Neovide's cursor renderer, ported: four critically damped springs, leading corners fast and trailing ones slow, drawn as one quad. TRAIL is Neovide's trail_size. smear.rs

The scroll

neoscroll's curves.

The parser

vte drives the state machine. The grid, cursor, modes, palette and responses are ours. src/lib.rs

The blocking

Brave's adblock engine, in CEF's resource request handler — so it works with nothing installed.

Read, not copied

Ghostty for VT state design and the Kitty protocols, Alacritty for vte in practice, WezTerm for ConPTY's quirks. The polish passes were researched against Rio, kitty, Warp, Dia, Arc, Zen, Vivaldi and Orion.

Type and icons

IBM Plex Mono and Newsreader, both OFL. Phosphor icons, MIT.
