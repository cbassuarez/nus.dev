# Platform marks

`apple.svg`, `windows.svg` and `linux.svg` are the official Apple logo, the
current Windows mark and Tux, taken from [Simple Icons](https://simpleicons.org)
16.33.0 (paths CC0 1.0). The only edits: the `<title>` is dropped because
`icon()` marks them decorative, `fill="currentColor"` is added, and the Windows
viewBox is padded to 27 so its solid square sits at the same optical weight as
the other two.

Linux is a registered trademark of Linus Torvalds, and Tux was drawn by Larry
Ewing with The GIMP. They appear here only to name the system each download is
for.
