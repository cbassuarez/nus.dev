# Maintainer

**Sebastian Suarez-Solis** designs and maintains nus independently.

nus began as the environment I wanted for my own daily work: a shell and a browser that understood they belonged to the same task. I care about the small details that make that useful: readable type, a useful history, the right shell beside the right page, and an assistant that remains a tool rather than the owner of the environment.

## Work contributed

Product and interaction design, application architecture, implementation, release engineering, documentation, fixes and maintenance are my contribution to this proposal. The **{{request}}** request is for external expenses and independent expertise, not a salary line.

The code and written decisions are available for inspection. This is an early, maintainer-led project; the grant does not create a support contract or a commitment to implement every request.
